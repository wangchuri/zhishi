## 1. 视觉定位

### 1.1 一句话

**知识书房气质**——像在书房里翻开一本学习笔记/世界观手册，而不是操作一个 SaaS 仪表盘或社交信息流。

### 1.2 关键词

| 要有 | 不要有 |
|------|--------|
| 书本、纸张、印刷感 | 霓虹、赛博、强发光 |
| 安静、可读、可沉浸 | 嘈杂、卡片墙、数据看板感 |
| 温暖纸色 + 沉稳墨色 | 纯白无菌 / 纯黑炫酷 |
| 细线、留白、层级清晰 | 厚阴影、大圆角、玻璃拟态堆叠 |
| 品牌名作为首屏主角 | 首屏塞满统计、标签、促销条 |
| 青绿点缀（如旧地图边缘标注） | 紫渐变/靛蓝科技风 |
| 学习内容的「目录感」 | 短视频式封面墙 |

### 1.3 情绪板（文字版）

- 旧地图边缘的青绿标注
- 小说扉页的衬线书名
- 书房灯光下的米白纸页
- 一点赭石，像火漆或页边批注
- 书架上一排书脊的书名与标签

## 2. 色彩系统

### 2.1 核心色板

| Token | 色值 | 用途 |
|-------|------|------|
| `--ink` | `#14212B` | 主文字、主按钮、强强调 |
| `--ink-soft` | `#2A3A47` | 次级文字、说明 |
| `--ink-disabled` | `#8C9398` | 禁用文字 |
| `--paper` | `#F3EFE6` | 页面主背景（纸色） |
| `--paper-2` | `#E8E2D4` | 略深纸色、分区底 |
| `--paper-deep` | `#DDD5C5` | 更深的纸色（hover 状态） |
| `--mist` | `#C5D0C8` | 柔和分隔、次要装饰 |
| `--sea` | `#1F5C5A` | 品牌强调、链接、选中态 |
| `--sea-bright` | `#2F8A86` | 悬停、亮一点的强调 |
| `--sea-subtle` | `rgba(31, 92, 90, 0.08)` | 淡青色底（选中行、标签底） |
| `--ember` | `#C45C26` | 点缀（类型标签、少量高亮） |
| `--ember-subtle` | `rgba(196, 92, 38, 0.08)` | 淡赭石底 |
| `--line` | `rgba(20, 33, 43, 0.12)` | 分割线、描边 |
| `--line-light` | `rgba(20, 33, 43, 0.06)` | 更淡的分隔 |
| `--shadow` | `0 18px 50px rgba(20, 33, 43, 0.12)` | 轻阴影（少用） |
| `--shadow-sm` | `0 4px 16px rgba(20, 33, 43, 0.08)` | 卡片悬停阴影 |

### 2.2 语义色

| 语义 | 色值 | 使用场景 |
|------|------|----------|
| 成功 | `#2C7A5A`（偏 sea 的墨绿） | 完成状态、已掌握标签 |
| 成功底 | `rgba(44, 122, 90, 0.08)` | 成功背景 |
| 警告 | `#C45C26`（同 ember） | 注意、待复习 |
| 警告底 | `rgba(196, 92, 38, 0.08)` | 警告背景 |
| 错误 | `#A0352B`（沉稳砖红） | 错误、未掌握 |
| 错误底 | `rgba(160, 53, 43, 0.08)` | 错误背景 |
| 信息 | `#2A3A47`（同 ink-soft） | 提示信息 |

### 2.3 背景层次

- 页面主背景：纸色渐变 `#EFE9DC → #F3EFE6 → #EBE6DB`
- 淡径向光晕（可选）：`radial-gradient(ellipse at 50% 0%, rgba(31,92,90,0.04) 0%, transparent 60%)`
- 首屏/英雄区：深色全幅平面（`#14212B` 或带青绿调），与内页纸色形成「封面 → 内页」的翻书感

### 2.4 使用原则

1. **大面积用纸色**，墨色只用于字与关键操作，避免大块黑底
2. **青绿（sea）是品牌色**，用于链接、选中、标签、关键交互反馈
3. **赭石（ember）克制使用**，只做类型标记或极少量点缀，不要铺满
4. **不要**用紫渐变、靛蓝科技风、或高饱和多色标签墙
5. 默认用细线描边代替厚边框和阴影

## 3. 字体系统

### 3.1 字体配对

| 角色 | 推荐字体 | 中文回退 | 用途 |
|------|----------|----------|------|
| **Display** | Fraunces | Songti SC / Noto Serif SC / 宋体 | 品牌名「知拾」、大标题、板块标题 |
| **Body** | Outfit | PingFang SC / 微软雅黑 / Noto Sans SC | 正文、导航、按钮、表单 |

> 气质来源：衬线标题 = 书名/扉页；无衬线正文 = 现代阅读舒适度。

### 3.2 CSS 实现

```css
--font-display: 'Fraunces', 'Songti SC', 'Noto Serif SC', '宋体', serif;
--font-body: 'Outfit', 'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC', sans-serif;
```

> 注意：若 Fraunces 未被引入，可先用 `'Fraunces', serif` 后备回退到系统衬线。  
> Outfit 同样需在 `index.html` 或 CSS 中 `@import`。也可用 Inter 作为后备无衬线。

### 3.3 字号阶梯

| 级别 | 大小 | 字重 | 行高 | 应用场景 |
|------|------|------|------|----------|
| Display XL | 42–72px | 700 | 1.1 | 广场品牌名「知拾」 |
| Display L | 28–40px | 700 | 1.15 | 页面主标题 |
| Display M | 22–28px | 700 | 1.2 | 区块标题、卡片名 |
| Title S | 16–18px | 500–600 | 1.3 | 列表项标题 |
| Body | 15–16px | 400 | 1.55–1.7 | 正文 |
| Caption | 13px | 400 | 1.4 | 元信息、时间、标签 |
| Small | 12px | 400 | 1.3 | 次要标注 |

### 3.4 排版细节

- 正文行高：**1.55–1.7**，长文更宽松
- 标题行高：**1.15–1.25**，可略收紧字距 `letter-spacing: -0.02em`
- Eyebrow/标签：`letter-spacing: 0.12em–0.16em`，大写英文
- 长文单列控制在 **36–42em**，避免一行过长

## 4. 形状、线与空间

### 4.1 圆角

| 元素 | 圆角 | 说明 |
|------|------|------|
| 卡片/面板/输入框/表单 | **4px** | 偏纸张裁切，不要大圆角 |
| 按钮/导航胶囊 | **999px** | 胶囊，与卡片形成对比 |
| 标签/Chip | **999px** | 同按钮风格 |
| 封面图/块级图片 | **0** 或跟随卡片 4px | — |
| 选框/复选框 | **2px** | 小圆角 |

### 4.2 描边与阴影

- **默认用细线描边**（`--line`），不用厚边框
- 阴影仅用于悬停抬起或浮层，**日常列表不要人人带阴影**
- 避免多层阴影、发光描边
- 禁用阴影：`shadow-none`
- 卡片默认：`border` + `shadow-none`；悬停：`shadow-sm` + 微上移

### 4.3 间距

- 页面水平边距：约 **4vw**，内容最大宽约 **1120px**
- 区块垂直节奏：约 **3–4rem**
- 卡片内边距：约 **1–1.25rem**
- 原则：**宁肯留白，也不要塞满**

## 5. 组件视觉规范

### 5.1 顶栏

- 半透明纸色 + 轻微模糊（类似毛玻璃但用纸色底）
- 细底边线 `border-b border-line-light`
- 左侧：品牌名 **知拾**（衬线 Display 字体）+ 小号英文副标
- 右侧：一级导航文字链接；主操作按钮用墨色底 + 纸色字胶囊

### 5.2 侧栏

- 纸色底 + 细右边线
- 导航项：未选中 = `ink-soft` 字，线框图标；选中 = 左侧 2px sea 色竖条 + 字变 `ink`
- 二级嵌套：缩进 + 更小字号
- 不设阴影，不设毛玻璃（顶栏已承担浮层感）

### 5.3 按钮

| 类型 | 样式 |
|------|------|
| Primary | `bg-ink text-paper`，悬停转 `bg-sea text-paper` |
| Secondary | `border border-line text-ink`，悬停 `border-sea text-sea` |
| Ghost | 无边框 `text-ink-soft`，悬停 `text-sea` |
| Nav pill | 未选中 `text-ink-soft`，选中 `bg-sea-subtle text-sea` |
| Icon | 圆形 36px，悬停 `bg-paper-2` |
| Danger | `bg-ember text-paper`，悬停更深 |

### 5.4 卡片

- 默认：`bg-paper-2` + `border border-line-light` + `rounded-[4px]`
- 可交互卡片悬停：`hover:shadow-sm hover:-translate-y-[2px]` + 0.2s transition
- 卡片标题用 `font-display` 衬线
- 不设卡片间的 gap 阴影重叠

### 5.5 标签 / Chip

| 类型 | 风格 |
|------|------|
| 筛选 Chip（未选中） | `border border-line text-ink-soft rounded-full px-3 py-1` |
| 筛选 Chip（选中） | `bg-sea text-paper rounded-full px-3 py-1` |
| 内容 tag | `text-sea text-[13px]` 小号文字，不加实心背景 |
| 类型 tag（文档类型） | `text-ember text-[12px] uppercase tracking-wider` |

### 5.6 输入框 / 表单

- `border border-line bg-paper rounded-[4px] px-3 py-2 text-body`
- Focus: `border-sea ring-1 ring-sea-subtle`
- Label：`text-ink-soft text-caption mb-1`（大写在 Eyebrow 场景可用 tracking-wider）
- 搜索框：左侧图标 + placeholder 文字

### 5.7 分割线

- `border-t border-line-light my-8`
- 部分场景用 `mist` 色做装饰性虚线分割

### 5.8 骨架屏 / 加载态

- 用 `bg-paper-2` 到 `bg-paper-deep` 的脉冲动画，不用原来的紫色

### 5.9 滚动条

- 保持当前 `scroll-thin` 风格，thumb 色改为 `--mist`

## 6. 页面应用要点

### 6.1 登录页 `/login`

- **扉页感**：品牌名「知拾」衬线 Display XL + 小号英文 "self-learning companion"
- 背景：深色全幅（`#14212B` 带青绿调）
- 表单区域：纸色面板 + 4px 圆角 + 细线输入框
- 底部：极简版权信息 `text-ink-soft text-caption`

### 6.2 Dashboard `/`

- **书房入口**：顶部品牌区 + 欢迎语 + 快捷入口胶囊
- 主内容：**知识库文档列表**（文件名 + 类型 ember tag + 摘要 + 更新时间）
- 下方次要区：学习统计小块（3–4 个数值卡片：文档数/知识点/掌握度/待复习）
- 不要卡片墙堆砌，用列表式布局

### 6.3 知识库 `/knowledge`

- **书架感**：文档列表 = 书脊目录（每项一行）
- 上传区：拖拽区 = 虚线框 + 纸色底 + 描述文字
- 文档分类筛选：上方一排 ember 和 sea 的标签行

### 6.4 文档阅读 `/knowledge/doc/:id`

- **长文阅读**：居中单栏（36–42em），白纸色底（`bg-paper`）
- 标题：衬线 Display M
- 正文：Body 字体，行高 1.7，字距舒适
- 右边栏（可选）：目录导航 + 词条链接

### 6.5 对话 Chat `/chat`

- **对谈笔记本**：左侧消息列表 = 对话条目标题 + 时间
- 右侧聊天区：消息气泡无圆角或极小圆角
  - 用户消息：`bg-sea text-paper`
  - AI 回复：`bg-paper-2 text-ink`
- 输入框：底部固定，细线框 + 发送胶囊

### 6.6 笔记 `/notes`

- **书桌感**：大面积编辑区（纸色背景）
- 左侧文档列表：缩略标题行
- 标题：衬线
- 正文编辑区：舒适行高，少量格式工具栏

### 6.7 知识图谱 `/graph`

- **旧地图感**：节点 = sea 色圆点，连线 = mist 细线
- 节点标签：caption 字号，字距略宽
- 背景纸色，不要深色图底

### 6.8 学习分析 `/analytics`

- **学习日志**：简单统计块（3–4 个），非仪表盘
- 图表：recharts 保持细线条 + 纸色底 + sea 色数据线
- 不要大面积卡片堆砌

### 6.9 题库生成 `/question-gen`

- **工具书感**：表单细线输入框 + 衬线预览标题
- 生成区域：纸色底 + 虚线分隔
- 结果列表：简约列表，sea 色链接

### 6.10 Quiz 答题 `/quiz`

- **试卷感**：题目用 `Title S` 字号，选项用 `Body` + radio 圈（2px 圆角）
- 正确/错误反馈：sea/ember 色文字 + 极淡底
- 不要游戏化闪卡风格

### 6.11 针对性训练 `/training/targeted/*`

- **习题本**：题目列表 + 错题标记（ember 侧标）
- 训练中：逐题模式，选项简洁
- 结果页：掌握度用 sea 色进度条（细条，不要大紫色）

### 6.12 设置 `/settings`

- **目录册**：左侧设置项列表（侧栏式），右侧详情
- 表单用细线输入框，开关用 sea 色 toggle
- 保持纸本色背景

## 7. 动效原则

目的是 **存在感与层级**，不是装饰噪音。

### 7.1 基础动效

1. **页面切换**：短促淡入 + 轻微上移（约 0.3–0.4s）
2. **卡片/列表悬停**：位移 2–4px + 阴影出现（0.2s）
3. **按钮悬停**：颜色过渡 + 轻微上移 1px（0.15s）

### 7.2 避免

- 循环闪烁
- 强弹跳
- 粒子特效
- 进场过长动画（>0.6s）

### 7.3 Time Function 建议

- 默认：`ease-out`
- 进入：`cubic-bezier(0.16, 1, 0.3, 1)`（轻微 overshoot）
- 离开：`ease-in`

## 8. 图像与插画

### 8.1 方向

- 封面/头图：氛围插画、纹理、抽象地图感均可
- 可用渐变色块做占位（原型即如此），正式环境再换真实图
- 使用 emoji 或 unicode 符号作为小型装饰（如 📖 ✏️ 🔍）

### 8.2 禁止

- 首屏贴满浮动徽章、促销贴纸
- 无意义的 3D 玻璃图标行列
- 和「知识书房」无关的赛博霓虹主视觉
