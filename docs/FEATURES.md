# 知拾：当前功能说明

本文只描述**本仓库现在已经做出来、界面上能进到的功能**，按使用路径整理。不写规划、不做对比。

形态：本机自用（单用户、无登录鉴权）。后端提供解析、出题、对话等能力；前端是 Web（也可由后端托管 `frontend/dist`）。使用前需要配置后端、大模型（`tina.env`），PDF 解析依赖 MinerU。

---

## 1. 能干什么（一条线）

1. 把资料放进知识库（学习区 / 生活区）
2. 解析成可分页阅读的内容，并抽出书本目录
3. 按页或按整本自动出题，题进全局题库（内容哈希去重）
4. 对着某本书刷题：对、错、「不会」；错/不会可看解析和原文，可叫辅导
5. 在书里伴读、划词做成笔记；也可以按知识库范围聊天
6. 看练习统计、针对薄弱点再练；另有计划、成就、画像等辅助页

---

## 2. 启动与连接

- **连接服务器**：首次打开需填写后端地址和昵称，通过健康检查后进入。
- **设置**：可查看/重新配置后端地址与连接状态。
- 后端启动后可直接提供前端静态页；支持 PWA。

---

## 3. 资料：上传、知识库、解析

### 3.1 上传

入口：上传资料。

- 文档：PDF、TXT、MD、DOCX，以及 CSV / JSON / HTML
- 图片 OCR：PNG / JPG / WebP
- 拍照识别（调用摄像头）
- 导入他人导出的书本包（zip）
- 上传后有进度：上传 → OCR/解析 → 索引；可识别重复内容（不重复入库）

### 3.2 知识库

- **学习区 / 生活区** 两套集合，文档按区管理
- 文档列表、状态（解析、出题等）
- 打开单篇：看解析后的正文、图（图床路径 `images/文件名`）
- 按页浏览（有分页时）
- 删除文档
- **导出书本包**：题目 + 资料打成 zip，可给别人导入

### 3.3 扫描件解析

独立页：上传后预览各页 Markdown，可改字，再导入知识库或下载。适合扫描件先人工看一眼再入库。

### 3.4 书本目录（学习路径）

- 对学习区文档，Agent 可提取章节、要点（tag 式知识点）
- 题库里某本书详情会展示目录；可重新提取
- 出题时会把目录当作标签参考

---

## 4. 出题

入口：出题页 → 选一本学习区文档。

- **按页出题**：左侧勾选页（可预览该页正文），设定每页题数（填 0 表示由模型按内容决定）
- **整本出题**：从题库某本书发起
- 单次页数、并行路数读配置（默认最多 30 页、同时最多 3 个页 Agent）
- 每页一个出题 Agent：优先用该页正文；可检索本页、取相邻页；用工具提交题目
- 进行中：出题页右侧看过程；题库横幅也可点开旁路观看（思考可折叠，工具只显示名称，多 Agent 按 id 分栏）
- 题入库：**全局题** + 文档引用；相同内容哈希则复用，不重复存题
- 可按文档删题、批量删题
- 题上带页码、标签、解析、原文片段、来源（书中原题 / AI 出的）

---

## 5. 题型与作答

| 类型 | 作答方式 |
|------|----------|
| 单选 | A/B/C/D |
| 填空 | 题干空位或若干空 |
| 简答 / 应用 | 文本；可由模型判分 |
| 自定义 | HTML（iframe）+ 作答字段；支持 `data-answer-key`；拖拽填图可通过 `zhishiSetAnswer` 回传 |

题干、选项、解析支持 Markdown 与 LaTeX；书中图片按相对路径显示。

答题三种结果：**正确 / 错误 / 不会**（主动点不会，不判对错）。

---

## 6. 刷题与辅导

### 6.1 题库

- 学习区文档列表，看哪本已有题、出题是否进行中
- 点进一本书：目录、知识点、该文档答题统计、开始练习、整本出题、导出、预览题目
- 预览题目：搜题干/标签，看题型与做过没有

### 6.2 练习会话

- 按文档选题组卷，进入逐题作答
- 提交后主区反馈：对错、解析；错/不会可带原文引用卡片
- **不会**、**找 Tina 讲讲**（本题辅导）
- 连对庆祝
- 结束页：对错不会统计

### 6.3 辅导 Agent

- 绑定当前题和来源文档/页
- 流式对话，引导理解，不是另开一场无关聊天

## 7. 阅读与问答

### 7.1 伴学

- 按页读书（电子书式排版，公式和原图）
- 进度、重点页标记
- 划词做成笔记（tip 到该书该页）
- 侧栏可就这本书对话

### 7.2 AI 对话

- 多会话，可指定知识库集合再问
- 流式回复；可带思考折叠
- 引用资料时，侧栏可打开引用并跳到文档

### 7.3 笔记

- 列表/卡片；含伴学划词和报告类笔记
- 搜索

---

## 8. 学情与习惯

### 8.1 学习分析

- 文档数、题量、作答次数、正确/错误/不会
- 知识点 tag 统计（正确率）
- 活跃热力图、连续学习天数
- 可生成学习报告（Markdown）

### 8.2 针对训练

- 按报告里的薄弱标签选题（错题/不会优先）
- 专项练习会话，同样可调用辅导
- 训练结束可看该次情况

### 8.3 首页

- 问候、快捷入口（题库 / 上传 / 对话 / 知识库）
- 搜索会进对话
- 最近文档与会话、建议、连续学习摘要

### 8.4 学习计划

- 计划与任务、月历
- 提醒接口存在（今日/列表类）

### 8.5 成就墙

- 徽章列表，已解锁 / 未解锁

### 8.6 个人学习画像

- 昵称；目标、知识标签为页面上的编辑（与后端画像是否完全打通以实际保存为准）

## 11. 后台能力（对应上面的功能）

- 知识库：集合、上传、状态、正文/页/图/分段、导出导入、目录提取
- 题目：列表、按页/整本/流式出题、进行中任务与 WebSocket 旁路、删除
- 练习：会话、提交答案（含模型判分）、结果
- 辅导、对话、伴学会话
- 统计、tag 分析、活跃与连续天数、学习报告
- 针对训练、首页建议
- 计划、任务、提醒、成就
- 笔记（含划词 tip）
- 扫描件预览与导入

大模型统一走 Tina Agent（`tina.env`）。出题、目录、对话、辅导、报告、伴学都走这套。
