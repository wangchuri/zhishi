# 复测单 · 第六轮：刷题浮窗（章节 / 题型 / 难度 / 数量 / 分布）

- **被测版本**：`master` 最新提交（本轮：刷题浮窗 + 题目难度）
- **本轮改动**（**后端 + 前端 + 提示词都改了**）：
  - 资料详情页原来的「从头开始 / 未做 / 错题 / 不会」四个选项 + 「试卷模式」面板**已删除**，换成一个「**刷题**」按钮 → 点开浮窗自选范围；「试卷模式」的能力并入浮窗的「分布」。
  - 题目新增**难度字段**（1 简单 / 2 中等 / 3 困难），由**出题 Agent 提交题目时判定**。**注意：老题没有难度标注**，所以只有「不限」才包含它们。
  - 后端创建会话新增：多章节 / 题型 / 难度 / 数量 / 分布（自定义每种题型数量）。
- **执行人**：有浏览器 / Playwright 的 QA（真机项需实体手机）
- **本轮重点**：浮窗里每个选择项**真的作用到本场题目上**（不是只改 UI）。

2. **重启后端**（本轮后端改了会话创建、题目入库、出题工具）。
3. 访问一次 **`/api/v1/pwa-reset`** 清 Service Worker，再刷新。
4. 视口：**390×844**（主）+ **1024×800**（断点）。
5. 账号：`wangchuri / wc19967501986`。
6. 数据：随便挑一本已有题库的书（如 `26张宇基础30讲（高数）_含目录.pdf`）；难度相关用例需要**新出一页题**（见 C 组）。

## 附：本轮已知的取舍（不是 bug，别报）

- **老题没有难度**：无法凭空推断，所以「勾具体难度」时它们一律不参与；「不限」才包含。若要给老题补标注，需要重新出题或人工标。
- **「未做 / 错题 / 不会」入口已移除**：本轮按需求去掉（错题仍可从题目详情页的作答记录看）。若要回来，需要重新设计进浮窗。
- **均衡随机是按题型轮转抽**：材料题按「整段材料」算一组，抽中会把该材料的所有子题一起带出来，所以本场题数可能比填的数量略多。
