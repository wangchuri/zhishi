## K. 已知限制（**不用报 bug**）

1. 历史回放只把**最近 2 轮**图片带给模型；更早的图仍在历史里显示，只是不重发（省 token 的设计）。
2. 同一场刷题内重答同题会**覆盖**该条记录；跨场次才新增。
3. 清理图片缓存后，旧记录中的图会打不开（见 `I3`）。
4. 手机浏览器可能缓存旧前端：需清 Service Worker 或访问 `/api/v1/pwa-reset`。
5. HEIC 等浏览器解不开的图不会被压缩，原样上传（属回退行为，非失败）。
6. 「拍照」按钮在电脑上会退化为普通文件选择（浏览器忽略 `capture`）。
7. 判题 / 对话依赖模型 API；**配额用尽导致的失败按环境阻塞处理**，不算功能 bug。
8. 单用户系统：只有一个账号，多端同时登录可能互相影响。
